A autoria legítima do código existente é preservada; este repositório independente não afirma criação exclusiva de todo o material no commit inicial. Autor registrado nos commits recentes de origem: patrick vitor.

Não havia arquivo de licença geral do código autoral entre os arquivos versionados de origem; esta preparação não inventa ou concede uma licença de terceiros. Publicação e reutilização devem respeitar os direitos dos autores e as regras da disciplina.

Dependências Flutter/Dart/Python/Docker mantêm suas próprias licenças, declaradas pelos respectivos pacotes/imagens. O build Web inclui assets/NOTICES gerado pelo Flutter; não remover esse arquivo. Referências arquiteturais em docs/ARCHITECTURE.md.

Este material é um protótipo acadêmico com dados fictícios. As regras acadêmicas aplicáveis de declaração de ferramentas e autoria continuam obrigatórias; não foram fornecidas regras adicionais específicas nesta preparação. Nenhum resultado ou histórico foi falsificado.
